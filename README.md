# campus-mutual-aid

华南理工大学校园互助小程序的交互原型。课程：交互设计导论。小组：第三组。

## 小组同步（2026-11-09）

产品规则：

- 闲置无偿转让，不做买卖，不标价。
- 借物押金由平台代管，信用 80 以上免押，归还后退回。
- 代取可自愿加打赏，由平台代收，确认送达后转给接单者。
- 支持大学城校区与广州国际校区切换，内容按校区隔离。

视觉规范：方向 B，冷白底 #F5F7FA，主色 #2F6BFF，辅助 #7C5CFF，具体见文末视觉规范。三段序列必须用同一套令牌。

分工，按上次分配，换人自行改：

## 这是什么

手机尺寸的可交互网页原型，前后端分离。前端只负责界面和交互，数据通过 HTTP JSON 接口读写。支持大学城校区和广州国际校区切换，闲置、借用和代取按校区隔离。产品不做买卖。闲置转让不涉及付款，借物押金由平台代管，归还后退回，代取可自愿加打赏，由平台代收，确认送达后转给接单者。互助行为完成后计入信用分，信用分用于免押金借用、优先展示和评审员资格。

## 运行

需要 Node.js 18 以上，无第三方依赖。

```
npm start
```

浏览器打开 http://127.0.0.1:3000

根目录只有 client 和 server 两个目录。client 里的 index.html 也可以直接双击打开，但这样不会连后端，信用分会用前端缓存值。

## 前后端分离

```
client/              前端，纯静态
  index.html         16 屏
  css/               设计令牌、手机框、组件
  js/api.js          唯一的网络层，集中所有 fetch
  js/app.js          界面状态与信用分展示
  js/router.js       屏幕切换与返回栈
  js/logger.js       可用性测试埋点与 CSV 导出

server/              后端，Node 内置 http，无依赖
  index.js           静态托管 + REST 接口
  store.json         运行时数据，自动生成，已加入 gitignore
```

前端不直接改后端数据，所有写操作走接口。后端返回最新的用户状态，前端用返回值覆盖本地缓存。

接口：

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | /api/health | 健康检查 |
| GET | /api/me | 信用分、记录、最近一次加分 |
| POST | /api/complete | 完成一次互助，加分并写记录 |
| POST | /api/undo | 撤回最近一次加分 |
| POST | /api/campus | 切换校区 |
| GET | /api/items | 闲置物品列表 |
| POST | /api/items | 发布闲置 |
| GET | /api/orders | 借用与代取订单 |
| POST | /api/orders | 创建借用或代取订单 |

## 三条流程

出闲置：发布，物品详情，站内消息，柜机交付，确认互评。
借物品：列表，借用详情，申请，归还。
互助：接单池，接单确认，代取任务，发布需求，进度，取餐凭证，确认。

页面左下角有两个按钮。导出测试日志会下载 CSV，记录每屏停留时长、点击次数和返回次数。重置会清空界面状态，不清后端数据。

## 设计依据

实体介质是丰巢柜和美团外卖柜。两个校区的柜机地点分开，切换校区后只显示本校区的闲置、借用和可接的单。出闲置的交付、借物的取还、代取的取餐都落在柜机上。

界面按附件 1 的八条原则逐条对照过。自我描述对应导航标题、步骤条、可识别图标和信用进度刻度。符合预期对应返回只回上一屏、底部标签不进返回栈。可学习对应信用怎么用弹层。可控与容错对应修改入口、两小时内撤回。可定制对应到期提醒和默认交付方式两个开关。

不做买卖之后，界面上不出现商品价格和议价。押金与打赏是两笔独立的钱，由平台代管代收，闲置转让本身不涉及付款。

代取分两侧。需求方发布，接单方在互助页的接单池里挑顺路的单，确认后进入任务页，取餐拍照上传，送达后双方各得 3 分。评审团相关功能本轮不做。


## GitHub Pages

仓库里的 `.github/workflows/pages.yml` 会把 `client` 目录发布到 GitHub Pages。Pages 只能托管静态文件，所以线上版本不带 Node 后端，信用分和校区状态存在浏览器里，刷新会回到初始值。

要连后端一起上线，用 `npm start` 在支持 Node 的环境运行，或者用内置托管发布整个项目目录。
